# Viking Chat ⚔️

Современный защищённый мессенджер — прототип в духе Telegram/WhatsApp.
Сезонные анимации: снег зимой, лепестки весной, искры летом, листопад осенью.

**Веб-версия:** https://vladislavdelon.github.io/Viking-Chat-Release/
**Скачать APK:** https://github.com/VladislavDelon/Viking-Chat-Release/releases

## Облачная синхронизация

Переписка хранится в приватном репозитории `VladislavDelon/Viking-Chat-Closed`
через GitHub Contents API — в репо попадает только AES-256-GCM шифротекст.

Подключение: Настройки ⚙️ → Облачная синхронизация → репозиторий + GitHub token.
Без токена работает локальный режим (localStorage). Синк опрашивает индекс каждые ~15 с.

## Запуск (веб)

```bash
npm install
npm run dev                  # dev: http://localhost:5173
npm run build                # production build в dist/
npx vite preview --host      # раздать build по локальной сети
```

Приложение — PWA: на Android откройте сайт в Chrome → «Установить приложение».

## Android

Готовый debug-APK: `VikingChat-debug.apk` в корне проекта.
Сборка из исходников:

```bash
npm run build                # обновить dist/
npx cap sync android         # скопировать в android-проект
cd android && gradlew.bat assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 17+ и Android SDK (`android/local.properties` → `sdk.dir=...`).

## Возможности

- **Авторизация** — вход по логину и паролю (PBKDF2-SHA-256, 120k итераций). При регистрации генерируется ключ аккаунта `VKNG-…`, который сохраняется локально и запрашивается при входе с «нового устройства».
- **Шифрование** — все сообщения шифруются AES-256-GCM (WebCrypto) до записи в хранилище; в «облаке» лежит только шифротекст `iv.ciphertext`. Расшифровка — только на устройстве.
- **Облачное хранилище** — слой `src/lib/cloud.ts` эмулирует облачный репозиторий (localStorage). API полностью асинхронный — реальный backend (REST/WebSocket) подключается заменой этого файла. Откройте приложение в двух вкладках — синхронизация между ними работает через событие `storage`.
- **Чаты** — личные, группы, каналы, «Избранное». Боты-собеседники (Лагерта, Рагнар, Флоки) отвечают автоматически (индикатор «печатает…»).
- **Медиа** — фото, видео и файлы до 8 МБ (хранятся внутри зашифрованного payload).
- **Поиск** — по чатам и по всем сообщениям, плюс поиск внутри открытого чата.
- **Уведомления** — in-app тосты, Web Notifications API, счётчик непрочитанных в заголовке вкладки.
- **Темы** — тёмная и светлая, переключение в шапке. Северный дизайн: стекло, градиенты, анимации framer-motion.
- **Сезоны** — `src/lib/season.ts` определяет текущий сезон по дате: фон экрана входа и падающие частицы меняются автоматически.
- **Адаптивность** — на узких экранах чат открывается поверх списка (как в мобильных мессенджерах).

## Архитектура

```
src/
  lib/crypto.ts   — WebCrypto: PBKDF2, AES-GCM Vault, генерация ключей
  lib/cloud.ts    — CloudRepository (асинхронный слой хранения, свап → backend)
  lib/seed.ts     — демо-контакты, группа и канал для нового аккаунта
  lib/season.ts   — определение сезона и набор частиц
  store/useStore.ts — zustand: сессия, сообщения, уведомления, синхронизация
  components/     — AuthScreen, SeasonalFx, Sidebar, ChatWindow, Composer, …
```

## Честные ограничения прототипа

- Облако — GitHub Contents API: каждый, у кого есть токен, может читать/писать репо. Держите его приватным и не публикуйте токен.
- E2E-шифрование реально (содержимое нигде не хранится в открытом виде), но ключ аккаунта — единый vault-ключ, а не per-chat ключевая пара с обменом, как в Signal Protocol.
- Чаты хранятся в неймспейсе владельца (`u/<login>/…`) — личные переписки двух разных аккаунтов пока не шарятся.
